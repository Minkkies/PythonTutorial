## วิธีรันโปรแกรม

### Q1 - โปรแกรมการเคลื่อนที่
```bash
cd Q1
python lab7-Q1.py
```

หมายเหตุ:
- โปรแกรมทั้งหมดใช้ os.chdir() เพื่อเปลี่ยน working directory ให้อยู่ในโฟลเดอร์เดียวกับไฟล์โค้ด
- ไฟล์ข้อมูล (.txt) ต้องอยู่ในโฟลเดอร์เดียวกับไฟล์ .py
