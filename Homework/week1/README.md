## บทนำและพื้นฐาน Python (Week 1)

เป้าหมายของสัปดาห์ที่ 1
- เรียนรู้พื้นฐาน Python และการใช้ variables
- ทำความเข้าใจชนิดข้อมูลพื้นฐาน (int, float, str, bool)
- ฝึกการรับค่า (input) และการแสดงผล (output)
- ใช้ตัวดำเนินการทางคณิตศาสตร์และตรรกะ
- เขียนโปรแกรมง่ายเพื่อแก้ปัญหา

สรุปสั้น ๆ ตามแต่ละ Lab
- Lab1_Q1 — เรียนรู้การประกาศตัวแปรและการใช้ print
- Lab1_Q2 — การรับค่าจากผู้ใช้ (input) และการแปลงชนิดข้อมูล
- Lab1_Q3 — การใช้ตัวดำเนินการทางคณิตศาสตร์ (+, -, *, /, //, %)
- Lab1_Q4 — การเปรียบเทียบและตัวดำเนินการตรรกะ (==, !=, <, >, and, or)
- Lab1_Q5 — การใช้ if/else สำหรับประเมินเงื่อนไข
- Lab1_Q6 — การดำเนินการกับสตริง (string slicing, concatenation)
- Lab1_Q7 — แบบฝึกผสมเพื่อรวมทักษะทั้งหมด

วิธีรันไฟล์ (Windows PowerShell / CMD)
- เปิดโฟลเดอร์ week1:
  - cd d:\git\PythonTutorial\Homework\week1
- รัน notebook: เปิดใน VS Code หรือ Jupyter แล้วรันแต่ละ cell (Shift+Enter)
- รันสคริปต์ .py:
  - python script_name.py

ตัวอย่างคำสั่งและเทคนิคที่ใช้บ่อย
- ประกาศตัวแปรและมอบค่า:
  ```py
  x = 10
  name = "Python"
  ```
- รับค่าจากผู้ใช้:
  ```py
  age = int(input("กรุณาใส่อายุของคุณ: "))
  ```
- การใช้ตัวดำเนินการทางคณิตศาสตร์:
  ```py
  sum = a + b
  power = 2 ** 3
  remainder = 10 % 3
  ```
- เงื่อนไข if/else:
  ```py
  if x > 0:
      print("x เป็นจำนวนบวก")
  else:
      print("x ไม่เป็นจำนวนบวก")
  ```
