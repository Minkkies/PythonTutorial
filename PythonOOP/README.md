# Python OOP (ภาษาไทย)

เอกสารชุดนี้สรุปแนวคิดการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming) ด้วยภาษา Python  
เหมาะสำหรับทบทวนพื้นฐานจนถึงหัวข้อประยุกต์

## รายการไฟล์
- `01_Basic.md` — พื้นฐาน OOP (Class, Object, Attribute, Method)
- `02_principles.md` — หลักการ OOP (Encapsulation, Inheritance, Polymorphism, Abstraction)
- `03_Abstract_Classes.md` — การใช้งาน Abstract Class และ `abc`
- `04_Operator_Overloading.md` — การ Overload ตัวดำเนินการ เช่น `+`, `==`, `str()`

## วิธีใช้งาน
1. เปิดอ่านไฟล์ตามลำดับ `01 -> 04`
2. ทดลองเขียนโค้ดตัวอย่างใน VS Code หรือ Jupyter Notebook
3. ปรับโจทย์เพิ่มเองเพื่อฝึกการออกแบบคลาส

## ความรู้พื้นฐานที่ควรมี
- ตัวแปร ชนิดข้อมูล ฟังก์ชัน
- `if/else`, loop
- โครงสร้างข้อมูลพื้นฐาน (list, dict)

## เป้าหมายการเรียนรู้
- เข้าใจแนวคิด OOP และนำไปใช้จริง
- ออกแบบคลาสให้โค้ดอ่านง่ายและขยายต่อได้
- ใช้ Abstract Class และ Operator Overloading ได้ถูกต้อง
