# 12. Tuple (ทูเพิล)

> **Tuple** คือโครงสร้างข้อมูลประเภทหนึ่งในภาษา Python ที่ใช้เก็บข้อมูลหลายรายการไว้ในตัวแปรเดียว Tuple มีลักษณะคล้ายกับ List แต่มีความแตกต่างที่สำคัญคือ **Tuple ไม่สามารถแก้ไขได้** (**immutable**) เมื่อสร้างขึ้นแล้ว

## คุณสมบัติหลักของ Tuple

1. **มีลำดับ (Ordered)**: สมาชิกใน Tuple จะถูกจัดเก็บตามลำดับที่เรากำหนด และสามารถเข้าถึงได้ผ่านดัชนี (index)
2. **ไม่สามารถเปลี่ยนแปลงได้ (Immutable)**: นี่คือความแตกต่างที่สำคัญที่สุด เมื่อ Tuple ถูกสร้างขึ้น เราไม่สามารถเพิ่ม ลบ หรือแก้ไขสมาชิกภายในได้
3. **ยอมรับค่าซ้ำ (Allows Duplicates)**: สามารถมีสมาชิกที่มีค่าซ้ำกันได้
4. **เก็บข้อมูลได้หลากหลายชนิด (Heterogeneous)**: สามารถเก็บข้อมูลต่างชนิดกันได้ เช่น ตัวเลข, ข้อความ, หรือ List

## การสร้าง Tuple

### การสร้าง Tuple โดยใช้วงเล็บ ()
> สามารถสร้าง Tuple ได้โดยการนำสมาชิกมาใส่ไว้ในวงเล็บ () และคั่นด้วยเครื่องหมายจุลภาค , (comma)

```python
# ตัวอย่างการสร้าง Tuple
my_tuple = ("apple", "banana", "cherry", 123)

# การสร้าง Tuple ที่มีสมาชิกเพียงตัวเดียว ต้องมีเครื่องหมายจุลภาคต่อท้าย
single_tuple = ("hello",)
print(type(single_tuple))
```

### การสร้าง Tuple โดยใช้ `tuple()` constructor

**`tuple()`** constructor เป็นฟังก์ชันที่ใช้สร้าง Tuple โดยรับ iterable (เช่น List, String, หรือ Tuple อื่นๆ) เป็นอาร์กิวเมนต์ ตัวอย่างเช่น

```python
# ใช้ tuple() constructor เพื่อสร้าง Tuple จาก List หรือ iterable อื่นๆ
tuple_constructor = tuple(['Jack', 'Maria', 'David'])
print(tuple_constructor)

**ผลลัพธ์: ('Jack', 'Maria', 'David')**
```

### Tuple ว่าง (Empty Tuple)

> สามารถสร้าง Tuple ที่ไม่มีสมาชิกได้โดยใช้เพียงวงเล็บเปล่า **`()`** หรือใช้ **`tuple()`** constructor ที่ไม่มีอาร์กิวเมนต์

```python
# สร้าง Tuple ว่าง
empty_tuple = ()
print(empty_tuple)
# ผลลัพธ์: ()
```

## Indexing & Slicing
```python
t = (10, 20, 30, 40, 50)
t[0], t[-1]        # 10, 50
t[1:4]             # (20, 30, 40)
t[:3], t[::2]      # (10, 20, 30), (10, 30, 50)
t[::-1]            # (50, 40, 30, 20, 10)
# t[0] = 99        # ❌ TypeError (immutable) แก้ไม่ได้
```

## Methods ที่มีให้ใช้งาน
```python
t = (1, 2, 2, 3)
t.count(2)   # 2
t.index(3)   # 3
# ไม่มี append/remove/extend เพราะ immutable
```

## Packing/Unpacking และ Starred Unpacking
```python
# Packing
pt = 13.0, 5.5          # (13.0, 5.5)

# Unpacking
x, y = pt               # x=13.0, y=5.5

# สลับค่า
a, b = 1, 2
a, b = b, a             # a=2, b=1

# Starred
first, *mid, last = (1, 2, 3, 4, 5)   # first=1, mid=[2,3,4], last=5
*head, tail = (10, 20, 30)            # head=[10,20], tail=30
```

## เปรียบเทียบกับ List แบบสั้น ๆ
- Tuple: คงที่, เหมาะกับข้อมูลไม่เปลี่ยน, ใช้เป็น dict key ได้
- List: แก้ไขได้, เหมาะกับข้อมูลที่เพิ่ม/ลบ/แก้บ่อย

```python
coords = (13.7, 100.5)         # ค่าคงที่ → tuple
items = ["apple", "banana"]    # รายการแก้ไขได้ → list
```

## ใช้งานจริงที่พบบ่อย
```python
# คืนค่าหลายตัวจากฟังก์ชัน
def min_max(nums):
    return min(nums), max(nums)
lo, hi = min_max([3, 1, 4])     # (1, 4)

# ใช้เป็น key ใน dict
dist = {}
dist[("A", "B")] = 12.5
dist[("A", "C")] = 7.8

# Nested tuple
matrix = ((1, 2), (3, 4), (5, 6))
first_col_sum = sum(row[0] for row in matrix)

# Concatenate/Repeat
(1, 2) + (3, 4)       # (1, 2, 3, 4)
(0,) * 5              # (0, 0, 0, 0, 0)
```

## แปลงชนิด & ทำงานร่วมกับชนิดอื่น
```python
lst = [1, 2, 3]
t  = tuple(lst)           # (1, 2, 3)
lst2 = list(t)            # [1, 2, 3]

tuple("ABC")             # ('A', 'B', 'C')
"-".join(map(str, (1, 2, 3)))  # '1-2-3'
```

## ข้อควรระวัง
```python
# Single-element ต้องมี comma
(42)     # ❌ ไม่ใช่ tuple (int ธรรมดา)
(42,)    # ✅ tuple

# Immutable เฉพาะระดับบนสุด
t = (1, [2, 3])
t[1].append(4)    # ✅ ได้ (แก้ภายใน list)
# t[1] = [2, 3, 4] # ❌ เปลี่ยน reference ไม่ได้
```
## ตารางสรุปเปรียบเทียบ (String • List • Dict • Set • Tuple)

| ชนิด | ลำดับ (Ordered) | แก้ไขได้ (Mutable) | ค่าซ้ำได้ | เข้าถึงด้วย Index | Literal/สร้าง | ใช้งานเด่น |
|---|---|---|---|---|---|---|
| String (`str`) | ใช่ | ไม่ | อักขระซ้ำได้ | ใช่ | `'...'`, `"..."`, `'''...'''` | ข้อความ, ประมวลผลตัวอักษร |
| List | ใช่ | ใช่ | ใช่ | ใช่ | `[ ... ]`, `list(...)` | ลำดับข้อมูลทั่วไป, เพิ่ม/ลบ/แก้ไขได้ |
| Dictionary (`dict`) | ใช่ (3.7+) | ใช่ | Key ห้ามซ้ำ, Value ซ้ำได้ | ไม่ (เข้าผ่าน key) | `{k: v}`, `dict(...)` | จับคู่ข้อมูลแบบ key→value, ค้นหาเร็ว |
| Set | ไม่ | ใช่ | ไม่ | ไม่ | `{...}`, ว่างใช้ `set()` | ค่าที่ไม่ซ้ำ, ยูเนียน/อินเตอร์เซกชัน |
| Tuple | ใช่ | ไม่ | ใช่ | ใช่ | `( ... )`, `tuple(...)` | ข้อมูลคงที่, คืนค่าหลายตัว, ใช้เป็น key ได้ |

หมายเหตุ:
- `{}` เป็น `dict`; เซตว่างให้ใช้ `set()`
- `dict` เก็บลำดับตามการแทรกตั้งแต่ Python 3.7 เป็นต้นไป
- การตรวจสมาชิก (`in`): `set`/`dict` โดยทั่วไปเร็วกว่า `list`/`tuple` สำหรับข้อมูลจำนวนมาก
